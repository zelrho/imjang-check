# 🏡 임장 체크리스트

집 보러 다니면서 폰으로 바로 체크하는 앱. 프레임워크·서버 없음, HTML 파일 하나.

👉 **https://zelrho.github.io/imjang-check/**

## 쓰는 법
1. 폰 브라우저로 열고 **홈 화면에 추가** — 앱처럼 뜨고 오프라인(지하주차장)에서도 열립니다.
2. `＋ 새 매물 추가` → 기본정보/시세 입력 (수원 단지는 프리셋에서 자동 입력)
3. 현장에서 상단 **딩구 / 저** 토글로 본인 선택 후 항목 탭
4. 기본은 **핵심 28개**만 보입니다. `전체 보기`로 72개 전부.
5. 저녁·출퇴근 때 다시 봐야 하는 항목은 🔁 → `비교` 탭에 모입니다.
6. 임장 끝나면 `백업` 탭에서 내보내서 서로 주고받고 → 불러올 때 **누구 기록인지** 고르면 합쳐집니다.

## 저장
- **저장 버튼이 없습니다.** 입력하면 0.4초 뒤 자동 저장(브라우저 localStorage).
- 앱을 열 때마다 직전 상태를 한 벌 보관 → `백업 > 되돌리기`로 복구.

## 서버 동기화 (선택)
`백업 > ☁ 서버 동기화`에 토큰을 한 번 넣으면 두 사람 기록이 비공개 저장소 `imjang-data`의
`data.json` 한 개로 자동으로 **합쳐집니다**. 앱을 열 때·끌 때·온라인 복귀 때 자동 실행.

- 덮어쓰기가 아니라 **병합**입니다: 항목별로 사람별 최신 기록이 남고, 상대 기록은 지워지지 않습니다.
- 동시에 저장해서 충돌(sha mismatch)이 나면 다시 받아 합친 뒤 재시도합니다.
- 토큰은 `imjang.token` 키로 **그 기기에만** 저장되고 내보내기 JSON에는 들어가지 않습니다.
- 토큰 발급: [fine-grained PAT](https://github.com/settings/personal-access-tokens/new) → Only select repositories `imjang-data` → Contents: Read and write
- 저장소 커밋 히스토리가 그대로 백업이라, 잘못 합쳐도 깃허브에서 이전 버전을 볼 수 있습니다.

## 개인정보
임장 기록(주소·동호수·가격·메모)은 **이 저장소가 아니라 각자 브라우저에만** 저장됩니다.
저장소에 올라가는 건 앱 코드와 공개된 단지 시세뿐입니다.

## 파일
- `index.html` — 앱 전체 (화면·이벤트)
- `data/checklist.js` — 항목 72개·인테리어 단가·단지 프리셋. **숫자와 항목은 전부 여기에만.**
- `lib.js` — 점수·견적·병합 로직 (순수 함수)
- `test.js` — `node test.js` 로 병합·점수 자체 점검
- `sw.js` / `manifest.json` — 오프라인·홈화면 추가
